# Source-material library

Editable source-material items live under:

```text
src/source-material/items/
```

The generated public source-material area lives under:

```text
docs/source-material/
docs/data/source_material_index.json
```

Build and check with:

```bash
python scripts/build_source_material_library.py
python scripts/build_source_material_library.py --check
```

For item format and maintenance notes, see the root file:

```text
SOURCE_MATERIAL_INDEX_EXPLAINER.md
```
