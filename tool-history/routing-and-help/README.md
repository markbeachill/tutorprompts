# Routing and help design history

This folder stores decision records and working papers about how students find tools and get help when they are stuck.

These files are design history, not live prompt instructions. If a behaviour from these notes is adopted, it should be implemented in `src/prompt-library/`, rebuilt into generated prompt libraries, and tested through the audit pack.

## Files

- `menus-help-and-routing.md` — working paper / decision record on menus, help systems and routing in the AI Personal Tutor Toolkit.
