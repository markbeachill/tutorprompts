# Tool history

This folder records past tool-development decisions, design rationales, release-era notes and approach documents.

Use it to understand how the toolkit got to its current shape. Do not treat documents here as current build instructions unless a current `project-docs/` file points back to them.

Suggested structure:

```text
tool-history/writing-tutor/       Writing Tutor design notes and routing decisions.
tool-history/site-design/         Past site/navigation/layout design notes.
tool-history/release-history/     Historical release-era notes.
tool-history/repository-docs/     Superseded root or repository documentation.
```

Current maintainer instructions live in `project-docs/` and the root `BUILD_AND_GENERATOR_GUIDE.md`.
