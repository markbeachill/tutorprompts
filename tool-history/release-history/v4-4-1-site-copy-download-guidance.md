# v4.4.1 — Site copy and download-guidance refresh

This minor release is a site/copy update rather than a tutor-behaviour update.

It keeps tool codes visible as stable handles, but shifts student-facing catalogue tables so tool names lead and codes support. It promotes Try It as the quickest route for users who already use ChatGPT or Gemini, reframes the no-ghost-writing boundary as a positive promise that the student’s work stays theirs, and reorganises Download guidance around practical prompt-size reliability.

The Download page now advises mini-libraries or single-tool prompts for free, limited or long-prompt-sensitive setups, and the master library for setups that handle long prompts reliably. This guidance is presented as a reliability preference, not a hard rule or a student/educator split.

No v4.4.0 help-system or EAL/ESL behaviour was intentionally changed.
