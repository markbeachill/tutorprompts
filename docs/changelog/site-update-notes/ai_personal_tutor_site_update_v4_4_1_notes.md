# AI Personal Tutor Toolkit site update v4.4.1

## Summary

v4.4.1 is a minor site/copy update. It does not change the tutor tool behaviour introduced in v4.4.0.

## What changed

- Promoted Try It as the quickest route for users who already use ChatGPT or Gemini.
- Updated homepage copy so the no-ghost-writing boundary is framed positively: the student’s work stays theirs.
- Kept tool codes visible, but made tool names lead in student-facing tool tables.
- Added Where to Start guidance that sends unsure users to Try It first.
- Reworked Download guidance around practical prompt-size reliability: mini-libraries and single-tool prompts for limited setups, master library for setups that handle long prompts reliably.

## What did not change

- No tool instructions or help-system behaviour changed beyond version stamping.
- EAL/ESL behaviour remains the v4.4.0 implementation.
- Routing and audit boundaries remain unchanged.
