# Site v4.2 — Writing Tutor router, flow and subject tools

**Site package:** v4.2  
**Prompt-library suite:** v4.2  
**Testing/audit pack:** v4.2

This release adds a Writing Tutor router and two new local writing tools, then renumbers the Writing Tutor family so the public menu starts cleanly at WT1.

## Main changes

- Added **WT1 — Which Writing Tool Should I Use?** as a Writing Tutor routing helper.
- Renumbered the existing Writing Tutor tools: Clarity Clinic is now WT2; Single Paragraph Analysis is now WT3; Find My Mistakes is now WT4; Teach Me This Mistake is now WT5; Style and Clarity Review is now WT6; Referencing Helper is now WT7; Paraphrase and Quotation Workshop is now WT8.
- Added **WT9 — Flow and Coherence: The Running Subject**.
- Added **WT10 — Learn Subjects: Parsing Your Own Sentences**.
- Updated the launcher/router so paragraph flow, subject/verb confusion and whole-piece requests route to the right tools.
- Updated audit/testing files to v4.2, including checks for WT1 routing, WT9 flow/coherence and WT10 subject/verb learning.
- Updated Tools, Where to start?, Examples, Download, Source material, Testing, Deployment check, Changelog and Release Manifest pages for v4.2.

## Compatibility note

Version 4.2 deliberately renumbers the Writing Tutor tools. When using older teaching notes or screenshots, check the tool title as well as the WT number.
