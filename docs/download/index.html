Download

Download prompt libraries and individual tools.

Download the prompt files if you want to use the toolkit in your own AI setup, keep local copies, inspect the instructions, or adapt the toolkit for a course or workflow.

Current release version: v4.4.1.

Which file should I download?

Use Try It instead if you simply want the quickest way to test the toolkit in ChatGPT or Gemini.

If you want the files, choose by what your AI setup can handle:

  • On a free plan, limited plan, or setup that struggles with long prompts: choose a mini-library or single-tool prompt. These are smaller and are usually more reliable on lighter setups.
  • On a paid plan or setup that handles long prompts reliably: choose the master library if you want every tool in one prompt.
  • If you want to inspect, adapt or reuse the toolkit in Projects, Gems or custom setups: download the files and choose the size that best fits your setup.

This is guidance, not a rule. The real question is whether your AI setup handles long prompts reliably.
